About This Project

A final project built with Vanilla HTML, CSS & JavaScript.

🛠️ Tech Stack

  • HTML5 Semantic Structure
  • CSS3 with Flexbox
  • Vanilla JavaScript (ES6+)
  • fetch + async/await
  • LocalStorage for favorites

📡 API Used

  • PokéAPI – pokeapi.co
  • Free, no key needed
  • All Pokémon loaded
  • Full stats, types & sprites

✨ Features

  • Search by name
  • Filter by type
  • Click for full details
  • Save to favorites (LocalStorage)
  • Loading / Error / Empty states
  • Responsive design

Made with ❤️ using PokéAPI • Vanilla JS
